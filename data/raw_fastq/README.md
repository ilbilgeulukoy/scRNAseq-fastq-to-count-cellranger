# Raw FASTQ files

This folder is reserved for raw 10x Genomics FASTQ files.

FASTQ files are not tracked in this GitHub repository because they are usually very large.

Expected file naming pattern for 10x Genomics data:

sample01_S1_L001_R1_001.fastq.gz
sample01_S1_L001_R2_001.fastq.gz
sample01_S1_L001_I1_001.fastq.gz

For a real project, FASTQ files should be stored on a server or HPC storage system.
